# To-Do App

Welcome to our To-Do app! This application allows you to manage your daily tasks with ease.

Features:
* Create, read, update, and delete (CRUD) tasks
* Filter tasks by priority and due date
* Mark tasks as completed

Usage Instructions:
1. Clone this repository using `git clone https://github.com/your-username/todo-app.git`
2. Install dependencies by running `pip install -r requirements.txt`
3. Run the app using `python todo_app.py`
4. Follow the in-app instructions to create, update, and delete tasks
5. Enjoy your organized daily life!
